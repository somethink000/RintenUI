# Third-party code

- **ThirdParty/Topten.RichTextKit** — RichTextKit by Topten Software, Apache License 2.0
  (https://github.com/toptensoftware/RichTextKit, http://www.apache.org/licenses/LICENSE-2.0).
  Copyright 2019-2020 Topten Software. Changed for Rinten: its colours and text effects.
- Much of Core/ and UI/ began as Facepunch's s&box UI (MIT, see LICENSE.md).
- **Razor/Rinten.Razor** — Microsoft's Razor compiler (Microsoft.AspNetCore.Razor.Language), MIT, as Rinten forked it.
- **Native/runtimes/linux-x64/native/libSDL3.so** — SDL 3.4 (https://libsdl.org), zlib licence, the build the Rinten engine ships.
- **Native/Shaders** — the Rinten engine's UI box shader, ported to GLSL.

NuGet packages: SkiaSharp and HarfBuzzSharp with their native assets (MIT), Svg.Skia (MIT), Zio (BSD-2-Clause), Humanizer.Core (MIT).
